# Instagram-Clone

A full-stack Instagram clone where users can share photos, follow other users, and interact with posts.

## Features

- User registration and login
- Create, view, and delete posts with images and captions
- Like and comment on posts
- Follow / unfollow users
- User profile pages
- Feed of posts from followed users

## Tech Stack

> Update this section to match the stack used in the project.

- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Authentication:** JWT

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm
- A running MongoDB instance

### Installation

```bash
git clone https://github.com/techsanjayfullstackdeveloper/Instagram-Clone.git
cd Instagram-Clone
npm install
```

### Run

```bash
npm start
```
